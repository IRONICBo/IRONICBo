# Hi, I'm Asklv

I build browser infrastructure and agent systems, especially the awkward edges where automation needs a person and then has to continue safely.

## What I'm working on

### [rea-captcha](https://github.com/masakaai/rea-captcha)

A Browser Use or Playwright run can get most of the way through a task and then stop at a verification page. `rea-captcha` keeps the page and browser session the agent already owns, pauses for an authorized test action or bounded human handoff, and resumes only after fresh evidence shows the current challenge cleared.

[Source](https://github.com/masakaai/rea-captcha) · [Four-case live demo](https://rea-captcha.vercel.app/) · [Product Hunt](https://www.producthunt.com/products/rea-captcha)

### [Jet Browser](https://github.com/masakaai/jet-browser)

A portable WPE WebKit runtime for agents with native input, screenshots, ordered JSONL, and reproducible benchmarks.
